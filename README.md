# U-Boot VIIC — Simulador de submarí

Simulador 3D de submarí Tipus VIIC (2a Guerra Mundial) inspirat en els clàssics simuladors U-boat, en un sol fitxer HTML.

Obriu `index.html` amb qualsevol navegador modern (Chrome, Firefox, Safari, Edge). Cal connexió a internet la primera vegada per carregar la llibreria Three.js des del CDN.

Inclou la missió d'entrenament de la 25a Flotilla d'Instrucció (badia de Danzig, 1941): navegació, immersió d'alarma, atac a un blanc estàtic, atac a un blanc en moviment amb TDC, evasió antisubmarina i retorn a la base.

Premeu F1 dins del simulador per veure tots els controls.
